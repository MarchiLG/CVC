# Detection and tracking. The torch package below installs the CPU
# variant by default from PyPI. On a machine with an NVIDIA GPU, install
# the CUDA variant BEFORE the rest of requirements.txt, following
# https://pytorch.org/get-started/locally/ (the exact command depends on
# the installed CUDA version) — device detection in vision/device.py is
# automatic at runtime, but the right wheel still has to be installed per
# machine.
#
# On Arch/CachyOS, skip the pip CUDA wheel entirely: install
# `python-pytorch-cuda` and `python-torchvision-cuda` via pacman instead
# (they track the driver's CUDA version and avoid pip/pacman conflicts),
# and create .venv with `python3 -m venv --system-site-packages .venv` so
# it can see them. pip install -r requirements.txt then leaves torch/
# torchvision alone ("Requirement already satisfied") instead of pulling
# in the CPU wheel on top.
torch
torchvision
